# ap30020-lab-report

Claude skill for processing raw AP30020 semiconductor lab data (E1–E9) into fitted plots and a written analysis section.

Skill lives at [`.claude/skills/ap30020-lab-report/SKILL.md`](.claude/skills/ap30020-lab-report/SKILL.md).

## Install

Copy the folder into your Claude skills directory:

```bash
cp -r .claude/skills/ap30020-lab-report ~/.claude/skills/
```
